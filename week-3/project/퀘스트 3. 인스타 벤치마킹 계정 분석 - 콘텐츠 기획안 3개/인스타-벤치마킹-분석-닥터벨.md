## 2. 반응이 좋았던 게시물의 공통점 3가지

### 공통점 ① 좋아요가 아니라 "댓글"을 목표로 설계했다 — 자료 배포형 참여 유도

폭발한 2개 게시물은 모두 **댓글을 남기면 정리본(자료)을 보내주는 구조**입니다.

| 게시물 | 좋아요 | 댓글 | 댓글/좋아요 |
|---|---:|---:|---:|
| 8번 환경호르몬 ("정리본 열심히 정리했어요") | 5,420 | 3,683 | 0.68 |
| 5번 기초대사량 | 845 | **5,546** | **6.56** |
| 계정 중앙값 | 251 | 18 | 0.07 |

- 5번은 **좋아요보다 댓글이 6.6배 많습니다.** 일반 게시물의 댓글/좋아요 비율(0.07)의 **약 94배**입니다.
- 16번째 이후 게시물에서도 같은 패턴이 확인됩니다. 4월 25일 릴스는 캡션이 통째로 `"댓글로 '에플힙' 남겨주시면 '엉덩이 운동 TIP' 정리본 보내드릴께요"`이고, 좋아요 204개에 댓글 61개(비율 0.30)로 **좋아요는 평범한데 댓글만 4배**입니다.
- 즉 이 계정의 히트작은 "좋은 콘텐츠라 반응이 왔다"가 아니라, **댓글 → DM 자료 발송이라는 리드 확보 장치를 콘텐츠에 심어둔 결과**입니다. 댓글 수는 인스타 알고리즘에서 가중치가 큰 신호이므로, 이 장치가 도달까지 끌어올린 것으로 보입니다.

### 공통점 ② 주제가 "제품·시술"이 아니라 "누구에게나 해당되는 생활 위험"이다

- 상위 2개의 주제는 **환경호르몬(생활 속 물건)** 과 **기초대사량(다이어트 기본 개념)** 으로, 팔로워 전원이 당사자인 주제입니다.
- 반면 **제품·광고성 게시물 7개**(1·3·7·12·13·15번 등)는 전부 좋아요 **110~372** 구간으로 중앙값 부근이거나 아래입니다. 자사 신제품 정식 런칭(12번)조차 310개에 그쳤습니다.
- 주의할 점은 **"지식형이면 무조건 터진다"가 아니라는 것**입니다. 10번(수부지 피부용 크림, 206개)과 11번(보톡스 내성, 124개)도 지식형이지만 성과가 낮았습니다. 두 건은 **대상이 좁습니다** — "수부지 피부인 사람", "보톡스를 반복해서 맞은 사람". 반대로 환경호르몬·기초대사량은 대상이 전 팔로워입니다.
- 정리하면 성과를 가른 축은 `지식형 vs 광고형`이 아니라 **`대상 폭이 넓은가`** 입니다.

### 공통점 ③ "통념을 뒤집는 교정형" 훅 + 의사 자격·본인 감량 서사로 근거를 세운다

- 8번 훅: **"생활 속 숨어있는 환경 호르몬! 당장 버리세요🥹"** → 위험 경고 + 즉시 행동 명령
- 5번 훅: **"기초대사량, 왜 중요할까요? / '저는 기초대사량이 낮아서 살이 잘 찌는 것 같아요.'"** → 팔로워가 실제로 하는 말을 인용한 뒤 교정
- 캡션은 **정의 → 흔한 오해 → 판단 기준 3가지** 순으로 구조화되어 있습니다. 7번 광고 캡션도 같은 틀("다이어트는 의지의 싸움이 아니었습니다 → 중요한 건 환경 → 이 3가지는 꼭 확인")을 쓰고, 10번도 "많은 분들이 이렇게 생각하는데, 실제로는… 저는 이 3가지를 봅니다"로 동일합니다.
- 이 틀의 설득력은 **화자 자격**에서 나옵니다. 캡션에 `100kg에서 60kg까지 감량하면서 깨달은 게 있습니다`, 프로필에 `40kg 감량 후 20년째 유지 중인 의사`가 반복 노출됩니다. **"의사"라는 전문성 + "본인이 겪었다"는 경험**이 한 문장 안에 함께 들어갑니다.

## 3. 콘텐츠 기획안 3개

위 3가지 공통점을 그대로 조합한 기획안입니다. 각 안은 `① 댓글 유도 장치`, `② 넓은 대상`, `③ 교정형 훅 + 자격 근거`를 모두 포함합니다.

### 기획안 A. "지금 당신 집에 있는 ○○, 오늘 버리세요" — 생활 점검 시리즈

| 항목 | 내용 |
|---|---|
| 포맷 | 릴스 40~60초 + 정리본 PDF |
| 훅 | "이거 아직도 쓰고 계신가요? 지금 바로 확인해보세요" |
| 구성 | 문제 물건 5가지 → 왜 위험한지 1줄씩 → 대체품 제안 |
| 댓글 유도 | "댓글에 **'체크'** 남겨주시면 「집안 점검 체크리스트」 보내드려요" |
| 대상 폭 | 전 팔로워 (집에 사는 모든 사람) |
| 벤치마킹 근거 | 8번 게시물(5,420/3,683)을 시리즈화. 단발이 아니라 회차를 붙여 재방문 유도 |

### 기획안 B. "○○ 때문에 살 안 빠진다고요? 진짜 원인은 따로 있습니다" — 오해 교정 시리즈

| 항목 | 내용 |
|---|---|
| 포맷 | 릴스 30~45초 + 긴 캡션(정의 → 오해 → 기준 3가지) |
| 훅 | 팔로워가 실제로 쓴 댓글·DM 문장을 그대로 첫 화면에 인용 |
| 구성 | 인용된 오해 → 의학적 설명 → "제가 보는 기준 3가지" |
| 댓글 유도 | "본인 상황을 댓글로 남겨주시면 다음 편에서 다뤄드려요" (다음 회차 소재까지 동시 확보) |
| 대상 폭 | 다이어트 경험자 전원 |
| 벤치마킹 근거 | 5번 게시물(845/5,546). 좋아요는 낮아도 **댓글로 도달을 만든** 유형이라 팔로워 규모가 작아도 재현 가능 |

### 기획안 C. "제 몸으로 1년 해봤습니다" — 본인 실험 기록

| 항목 | 내용 |
|---|---|
| 포맷 | 캐러셀 이미지 5~7장 (수치·전후 비교 그래프 중심) |
| 훅 | "의사인 제가 직접 12개월 해보고 남은 데이터입니다" |
| 구성 | 시작 수치 → 매월 변화 → 실패한 방법 → 남길 만한 방법 |
| 댓글 유도 | "댓글에 **'기록'** 남겨주시면 제가 쓴 기록표 양식 드려요" |
| 대상 폭 | 건강 관리를 시작하려는 전 팔로워 |
| 벤치마킹 근거 | 공통점 ③의 "자격 + 경험" 조합을 콘텐츠 전면에 세운 안. 이 계정에서 광고가 아닌 게시물 중 브랜드 서사(9번, 442개)가 제품 게시물보다 성과가 높았던 점도 근거 |

## 4. 이 계정을 벤치마킹할 때 주의할 점

1. **성과 편차가 극단적입니다.** 15개 중 13개는 좋아요 110~442로, 30.6만 팔로워 대비 참여율이 0.1% 미만입니다. 팔로워 수를 성과로 착각하면 안 됩니다.
2. **제품·광고 게시물이 절반에 가깝습니다.** 프로필 링크(litt.ly), 하이라이트(알약패치·마시는 샐러드·마샐 레시피 등)가 전부 자사 브랜드 @medison.bell 로 연결됩니다. 콘텐츠 전략이 곧 커머스 퍼널입니다.
3. **협업 게시물이 그리드에 섞여 있습니다.** 2·3·4·11번은 상대 계정이 원 작성자인 공동 작업 게시물이라, 순수 자기 콘텐츠 성과와 분리해서 봐야 합니다.
4. **정리본 배포 방식은 확인이 필요합니다.** 댓글→DM 자동 발송은 서드파티 도구(ManyChat 등)를 쓰는 경우가 많고, 인스타 정책·개인정보 처리 기준을 함께 검토해야 합니다.
