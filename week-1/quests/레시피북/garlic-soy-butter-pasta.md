# 마늘 간장 버터 파스타 (15분)

![마늘 간장 버터 파스타 - 오후 햇살이 드는 부엌 식탁 위에 놓인 윤기 나는 간장 파스타와 반숙 프라이](images/garlic-soy-butter-pasta.jpg)

집에 늘 있는 재료로 만드는 감칠맛 폭탄 파스타. 면 삶는 시간 안에 소스가 완성되기 때문에 실제 조리 시간은 15분을 넘지 않는다.

- **소요 시간**: 15분 (준비 5분 + 조리 10분)
- **분량**: 1인분
- **난이도**: 쉬움

## 재료

| 재료 | 분량 | 메모 |
| --- | --- | --- |
| 스파게티 면 | 100g | 손으로 잡아 500원 동전 굵기 |
| 마늘 | 5~6쪽 | 편으로 얇게 썬다 |
| 버터 | 20g | 무염 버터 권장 |
| 올리브유 | 1큰술 | |
| 진간장 | 1.5큰술 | |
| 설탕 | 1/2작은술 | 간장의 짠맛을 잡아준다 |
| 면수 | 1국자 (약 100ml) | 버리지 말 것 |
| 후추 | 약간 | |
| 대파 또는 쪽파 | 1/2대 | 송송 썰어 마무리용 |
| (선택) 페페론치노 | 1~2개 | 매콤하게 먹고 싶다면 |

## 만드는 법

1. **물 올리기 (0분)** — 냄비에 물 1.5L를 붓고 소금 1큰술을 넣어 센 불에 올린다. 물이 끓는 동안 마늘을 편 썰고 대파를 송송 썬다.
2. **면 삶기 (4분)** — 물이 끓으면 면을 넣고 포장지에 적힌 시간보다 **1분 짧게** 삶는다. 나머지 1분은 소스에서 익힐 것이다.
3. **마늘 볶기 (6분)** — 면이 삶아지는 동안 팬에 올리브유와 버터 절반을 두르고 **약불**에서 마늘을 볶는다. 가장자리가 연한 갈색이 될 때까지 3분 정도, 절대 센 불로 태우지 않는다.
4. **소스 만들기 (9분)** — 마늘 향이 올라오면 간장과 설탕을 넣고 10초만 끓인다. 간장이 팬 바닥에 살짝 타면서 나는 불향이 이 요리의 핵심이다. 바로 면수를 부어 자글자글 끓인다.
5. **면 합치기 (11분)** — 건진 면을 팬에 넣고 중불에서 1분간 볶듯이 섞는다. 소스가 면에 착 감기며 걸쭉해진다.
6. **마무리 (13분)** — 불을 끄고 남은 버터 절반을 넣어 잔열로 녹이며 빠르게 섞는다. 이때 넣는 버터가 소스에 윤기를 만든다. 후추를 갈아 넣고 대파를 뿌려 완성.

## 성공 포인트

- **면수는 반드시 남긴다.** 면수의 전분이 기름과 간장을 하나로 묶어주는 유화제 역할을 한다. 면수 없이 만들면 소스가 겉돌고 기름지다.
- **마늘은 약불에서 천천히.** 센 불에 볶으면 겉만 타고 속은 매운맛이 남는다.
- **버터는 두 번에 나눠 넣는다.** 처음 것은 향, 마지막 것은 광택과 부드러움을 담당한다.
- **간장은 팬에 직접 닿게.** 면수에 섞어 넣으면 그냥 짠 국물이 되고, 팬 바닥에 지져야 불향이 난다.

## 응용

- **참치 버전** — 4번 단계에서 기름 뺀 참치캔 1/2개를 넣는다.
- **베이컨 버전** — 1번 단계에서 베이컨을 먼저 바삭하게 굽고, 그 기름에 마늘을 볶는다. 올리브유는 생략.
- **달걀 얹기** — 반숙 프라이를 올리면 노른자가 소스와 섞여 훨씬 부드러워진다.
- **우동면 버전** — 스파게티 대신 냉동 우동면을 쓰면 삶는 시간이 2분으로 줄어 전체 10분에 완성된다.
