# 들기름 막국수 (10분)

![들기름 막국수 - 검은 그릇에 담긴 메밀면 위에 김가루와 들기름, 반숙 달걀](images/perilla-oil-noodles.jpg)

양념 없이 들기름과 간장만으로 끝내는 비빔면. 재료가 적을수록 들기름의 고소함이 선명해진다. 여름에는 시원하게, 겨울에는 미지근하게 먹어도 좋다.

- **소요 시간**: 10분 (준비 3분 + 조리 7분)
- **분량**: 1인분
- **난이도**: 아주 쉬움

## 재료

| 재료 | 분량 | 메모 |
| --- | --- | --- |
| 메밀 막국수면 | 1인분 (100g) | 소면이나 소바면도 가능 |
| 들기름 | 1.5큰술 | 갓 짠 것일수록 좋다 |
| 진간장 | 1큰술 | |
| 식초 | 1작은술 | 넣으면 훨씬 개운하다 |
| 설탕 | 1/2작은술 | |
| 김가루 | 넉넉히 한 줌 | 조미김을 부숴도 된다 |
| 달걀 | 1개 | 반숙 또는 완숙 |
| 통깨 | 1작은술 | 손으로 비벼 넣는다 |
| 쪽파 | 1대 | 송송 썰기 |
| (선택) 백김치 또는 열무김치 | 약간 | 곁들임 |

## 만드는 법

1. **물 올리고 달걀 삶기 (0분)** — 냄비에 물을 넉넉히 올리고, 달걀을 먼저 넣어 7분 삶는다. 반숙 노른자를 원하면 7분, 완숙은 10분.
2. **양념장 만들기 (2분)** — 그릇에 간장, 들기름, 식초, 설탕을 넣고 섞어둔다. 면을 담을 그릇에 바로 만들면 설거지가 하나 준다.
3. **면 삶기 (5분)** — 달걀을 건져 찬물에 담그고, 같은 물에 면을 넣어 포장지 시간대로 삶는다. 메밀면은 보통 3~4분. 넘칠 것 같으면 찬물 반 컵을 부어 진정시킨다.
4. **찬물에 헹구기 (8분)** — 면을 체에 밭쳐 찬물에 30초간 박박 문지르듯 헹군다. 표면 전분을 완전히 씻어내야 면이 쫄깃해지고 양념이 겉돌지 않는다. **물기는 손으로 꽉 짜낼 정도로** 털어낸다.
5. **비비기 (9분)** — 양념장 그릇에 면을 넣고 젓가락으로 30초간 충분히 비빈다. 면이 반질반질 윤이 나면 됐다.
6. **올리기 (10분)** — 김가루를 산처럼 수북이 올리고, 반 자른 달걀, 쪽파, 통깨를 얹는다. 김이 젖기 전에 바로 먹는다.

## 성공 포인트

- **물기를 남기지 않는다.** 이 요리의 유일한 실패 요인이다. 물이 남으면 들기름 향이 다 날아가고 밍밍해진다.
- **들기름은 신선한 것으로.** 들기름은 산패가 빠르다. 개봉 후에는 냉장 보관하고 한 달 안에 쓴다.
- **김가루는 아끼지 않는다.** 간장 양념과 들기름 사이를 이어주는 것이 김의 감칠맛이다. 생각보다 두 배 넣어도 된다.
- **면은 찬물에 헹군다.** 뜨거운 채로 비비면 들기름 향이 증발하고 면이 퍼진다.

## 응용

- **들기름 비빔밥** — 면 대신 찬밥에 그대로 비비면 3분 만에 완성.
- **김치 추가** — 잘게 썬 묵은지를 넣으면 새콤한 맛이 더해져 훨씬 풍성해진다.
- **명란 막국수** — 명란 반 덩이를 껍질 벗겨 올리면 짭조름한 별미가 된다.
- **국물 버전** — 찬 육수나 동치미 국물을 자작하게 부으면 여름용 들기름 냉국수.
