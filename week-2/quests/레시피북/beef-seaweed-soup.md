# 소고기 미역국 (15분)

![소고기 미역국 - 김이 오르는 뽀얀 국물과 짙은 초록 미역이 담긴 흰 대접, 아침 햇살이 드는 밥상](images/beef-seaweed-soup.jpg)

생일이 아니어도 먹고 싶은 날이 있는 국. 정통 방식은 미역을 30분 불리고 국물을 오래 우리지만, 자른 미역을 뜨거운 물에 불리고 얇은 소고기를 쓰면 15분 안에 같은 맛에 도달한다. 국물이 뽀얗게 우러나는 시점을 볶기 단계에서 미리 만들어두는 것이 핵심이다.

- **소요 시간**: 15분 (준비 5분 + 조리 10분)
- **분량**: 2인분
- **난이도**: 쉬움

## 재료

| 재료 | 분량 | 메모 |
| --- | --- | --- |
| 자른 미역 (건미역) | 10g | 불리면 8배로 늘어난다. 한 줌이면 충분하다 |
| 뜨거운 물 | 500ml | 미역 불림용, 70도 이상 |
| 소고기 | 100g | 샤브샤브용·불고기감처럼 얇게 썬 것. 국거리 양지는 15분 안에 부드러워지지 않는다 |
| 물 | 700ml | 국물용 |
| 참기름 | 1큰술 | 밑간용 1작은술 + 볶음용 2작은술 |
| 국간장 | 2큰술 | 밑간용 1/2큰술 + 간 맞추기용 1.5큰술 |
| 다진 마늘 | 1/2큰술 | |
| 소금 | 약간 | 마지막 간 조절용 |
| 후추 | 약간 | 고기 밑간용 |
| (선택) 참치액 | 1작은술 | 5번 단계에서, 감칠맛을 한 겹 더한다 |
| (선택) 들기름 | 1작은술 | 마지막에 한 방울, 고소한 향을 세운다 |

## 만드는 법

1. **미역 불리기 (0분)** — 자른 미역 10g을 볼에 담고 뜨거운 물 500ml를 붓는다. 찬물이면 25분 걸리는 일을 **뜨거운 물이 5분으로 줄인다**. 미역이 물 위로 뜨면 숟가락으로 눌러 완전히 잠기게 한다.
2. **소고기 밑간 (2분)** — 미역이 불어나는 동안 얇은 소고기 100g에 국간장 1/2큰술, 다진 마늘 1/2큰술, 참기름 1작은술, 후추를 넣고 손으로 버무린다. 미리 간장을 입혀야 볶을 때 겉면이 빠르게 갈변하며 감칠맛이 생긴다.
3. **미역 헹구고 짜기 (5분)** — 불린 미역을 찬물에 두 번 헹궈 미끈거리는 점액을 씻어내고, 두 손으로 꽉 짠다. 물기를 안 짜면 다음 단계에서 기름이 튀고 볶아지지 않고 삶아진다.
4. **고기와 미역 볶기 (7분)** — 냄비에 참기름 2작은술을 두르고 **중불**에서 소고기를 2분 볶는다. 고기 색이 반쯤 변하면 미역을 넣고 3분 더 볶는다. 미역 가장자리가 짙은 초록으로 변하고 냄비 바닥에 갈색 자국이 생기면 제대로 된 것이다.
5. **물 붓고 끓이기 (10분)** — 물 700ml를 붓고 **센 불**로 5분 끓인다. 볶을 때 나온 기름과 물이 세게 부딪히며 국물이 뽀얗게 유화된다. 참치액을 쓴다면 이때 넣는다. 위에 뜨는 회색 거품은 걷어낸다.
6. **간 맞추고 완성 (15분)** — 불을 끄기 직전 국간장 1.5큰술을 넣고 30초 더 끓인 뒤, 부족한 간은 소금으로 맞춘다. 국간장으로만 간을 다 맞추면 국물이 거무스름해진다. 대접에 담고 들기름을 한 방울 떨어뜨린다.

## 성공 포인트

- **미역은 반드시 물기를 꽉 짠다.** 물을 머금은 미역을 기름 두른 냄비에 넣으면 사방으로 기름이 튀고, 볶이는 대신 삶아져 4번 단계의 갈색 자국이 생기지 않는다. 그러면 국물도 끝까지 맑고 밍밍하다.
- **볶는 단계를 건너뛰지 않는다.** 재료를 처음부터 물에 넣고 끓이면 30분을 끓여도 뽀얀 국물이 나오지 않는다. 15분 미역국의 국물 맛은 전부 4번 단계에서 만들어진다.
- **국간장은 두 번에 나눠 넣는다.** 밑간용은 고기 맛을 잡고, 마지막 것은 국물의 간을 잡는다. 처음에 다 넣으면 짠맛만 세고 향은 날아간다.
- **미역을 너무 많이 넣지 않는다.** 건미역 10g은 불리면 80g이 된다. 눈으로 보고 적어 보인다고 20g을 넣으면 냄비가 미역으로 꽉 차고 국물이 사라진다.
- **거품은 반드시 걷는다.** 5번 단계에서 뜨는 회색 거품은 고기의 핏물 단백질이다. 그대로 두면 국물에서 누린내가 난다.

## 응용

- **들깨 미역국** — 6번 단계에서 들깻가루 2큰술을 풀면 걸쭉하고 구수해진다. 이때 참기름은 생략한다.
- **홍합 미역국** — 4번 단계에서 소고기 대신 손질한 홍합 10개를 넣는다. 물은 600ml로 줄여야 짜지 않다.
- **미역국밥** — 5번 단계에서 물을 500ml로 줄이고 밥 1공기를 바로 넣어 3분 끓이면 국밥이 된다.
- **참치 미역국** — 소고기 대신 기름 뺀 참치캔 1개를 4번 단계에서 넣는다. 볶는 시간은 1분이면 충분하다.
- **맑은 미역국** — 참기름 대신 물 2큰술로 재료를 볶으면 기름기 없는 담백한 버전이 된다. 대신 국물은 뽀얗지 않고 맑다.
