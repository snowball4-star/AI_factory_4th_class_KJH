# 문화 지출 분석

- 분석 대상: 가계부 DB의 `문화` 카테고리 지출 171건 (2022-06-20 ~ 2026-09-17)
- 데이터 출처: 로컬 가계부 앱 API `GET http://localhost:5001/api/transactions` (2026-09-19 조회)
- 총 지출: **17,223,853원**

> 요약: 문화 지출은 해마다 빠르게 늘고 있고, 금액의 약 78%가 **해외여행과 전자·오디오 기기 구입**이다.
> 매달 꾸준히 나가는 지출은 책과 구독료 정도다.

## 5. 정리

- **여행이 있는 달에 크게 튄다.** 2024-09 스페인, 2025-10 밀라노 항공권, 2026-07 이탈리아 예약처럼
  가을 여행을 준비하는 달에 지출이 몰린다. 여행이 없는 달은 대체로 월 3만~20만 원이다.
- **2026년에는 큰 기기 구입이 겹쳤다.** 2월 WiiM 스피커, 7월 삼성TV까지 전자·오디오 408.9만 원이
  모두 2026년에 나갔다.
- **책은 꾸준히 산다.** 매년 31만~81만 원이 들고, 문화 항목에서 가장 자주 나가는 지출이다.
- **구독료는 작지만 늘고 있다.** 넷플릭스·구글·Tidal이 2024년 6.1만에서 2025년 23.4만으로 늘었다.

## 참고: 데이터 한계

- API가 거래를 **정확히 2,000건**(id 1~2000)만 돌려주고 `limit`·`page`·`offset` 파라미터에 반응하지 않는다.
  DB에 그보다 많은 거래가 있다면 서버가 잘라서 보내는 것일 수 있어, 빠진 내역이 있을 수 있다.
